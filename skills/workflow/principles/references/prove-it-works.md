# Prove it works
Done means an outcome you can show, with evidence, not effort you spent.

- State the observable result before starting.
- Check each acceptance criterion against evidence.
- Paste the real command output, not a summary of it.
- Show before and after when you fix something.
- Label every claim measured, inferred or guessed.
- Before accepting, confirm the report, commits and changed files exist, allowed files were respected, and checks passed.
- A report without evidence is not done.
