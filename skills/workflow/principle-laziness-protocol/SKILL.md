# Laziness protocol
The best change is the smallest one that fully works.

- Check whether the repo already has the function, skill or pattern.
- Write only what the goal needs; no speculative options or fallbacks.
- Prefer deleting or reusing over adding.
- No unrelated fixes in the same change.
