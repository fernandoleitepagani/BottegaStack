# Attack the premise
Restate the request as an outcome, not a solution.

- Ask what would make the request wrong: wrong problem, metric or constraint.
- Name a smaller or different option, then say why the request wins or loses.
- Build only after the premise survives the questions.
- If the premise fails, propose the better problem instead.
