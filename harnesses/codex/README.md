# Codex Harness

Everything in this directory is exclusive to **Codex**.

## Install

```bash
./harnesses/codex/install.sh
```

Symlinks all 16 skills into `~/.codex/skills/bottega-<name>`. Uninstall with `./harnesses/codex/install.sh --uninstall`.
