# OpenCode Harness

Everything in this directory is exclusive to **OpenCode**.

## Install

```bash
./harnesses/opencode/install.sh
```

Symlinks all 12 skills into `~/.config/opencode/skills/bottega-<name>`. Uninstall with `./harnesses/opencode/install.sh --uninstall`.
